PC Shop AI Assistant

PC Shop AI Assistant is an automation project built using n8n. It helps customers get information about PC components, inventory, prices, warranties, and gaming PC configurations.

About the Project

The assistant uses inventory information provided by the PC shop to answer customer questions. It is designed to provide helpful information and refer customers to a human salesperson when information needs verification.
